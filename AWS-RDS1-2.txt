## 🧪 Lab Title: Deploy a Node.js + MySQL App using AWS EC2, RDS, and Docker

---

## ✅ Objective:

* Create and configure an **RDS MySQL Database**
* Launch an **EC2 instance**
* Deploy a **Node.js application using Docker**
* Connect the app to the RDS database

---

## 🧱 1. RDS MySQL Database Setup

### 🔹 Step 1: Create MySQL RDS

* Go to **AWS Console > RDS > Create database**
* Choose **Standard create**
* Engine: **MySQL**
* Version: **8.0.x**
* DB instance identifier: `database-1`
* Master username: `admin`
* Master password: `your-password`
* DB instance class: `db.t3.micro` (Free Tier)
* Storage: General Purpose SSD (20 GB)
* Uncheck “Enable storage autoscaling” (optional for learning)
* Connectivity:

  * VPC: Default
  * Public access: **Yes**
  * VPC security group: Create new or select existing

    * Add Inbound rule:

      * Type: MySQL/Aurora
      * Port: 3306
      * Source: **Anywhere (0.0.0.0/0)** (for test only)

➡️ Wait 5–10 minutes until the DB status is **Available**

### 🔹 Step 2: Note RDS Endpoint

Example:

```bash
database-1.cxumw2gemspm.eu-north-1.rds.amazonaws.com
```

---

## 🖥️ 2. Launch EC2 Instance

### 🔹 Step 1: Launch EC2

* Go to EC2 > Launch Instance
* Name: `ec2-node-docker`
* Amazon Linux 2 AMI (64-bit)
* Instance type: `t2.micro`
* Key Pair: Create or select existing
* Security Group:

  * Add rule: SSH (port 22), MySQL (3306), and HTTP (80)
  * Source: Anywhere (0.0.0.0/0)

### 🔹 Step 2: Connect to EC2

```bash
ssh -i your-key.pem ec2-user@your-ec2-public-ip
```

---

## 🐳 3. Docker + Node.js App Setup in EC2

### 🔹 Step 1: Install Docker

```bash
sudo yum update -y
sudo yum install docker -y
sudo service docker start
sudo usermod -aG docker ec2-user
```

(Reconnect EC2 SSH after this)

---

### 🔹 Step 2: Install Node.js and Git (Optional)

```bash
curl -sL https://rpm.nodesource.com/setup_18.x | sudo bash -
sudo yum install -y nodejs git
```

## 🧾 4. Node.js App + MySQL Code

### 📁 Project Folder Structure

```
node-mysql-app/
│
├── Dockerfile
├── package.json
├── index.js
```

---

### 🔹 `package.json`

```json
{
  "name": "node-mysql-app",
  "version": "1.0.0",
  "main": "index.js",
  "dependencies": {
    "express": "^4.18.2",
    "mysql": "^2.18.1"
  }
}
```

---

### 🔹 `index.js`

```js
const express = require('express');
const mysql = require('mysql');

const app = express();
const port = 3000;

const connection = mysql.createConnection({
  host: 'database-1.cxumw2gemspm.eu-north-1.rds.amazonaws.com',
  user: 'admin',
  password: 'your-password',
  database: 'practice_db'
});

connection.connect((err) => {
  if (err) {
    console.error('Database connection failed:', err.stack);
    return;
  }
  console.log('Connected to database.');
});

app.get('/', (req, res) => {
  connection.query('SELECT * FROM users', (err, results) => {
    if (err) throw err;
    res.json(results);
  });
});

app.listen(port, () => {
  console.log(`App running on http://localhost:${port}`);
});
```

---

### 🔹 `Dockerfile`

```dockerfile
FROM node:18
WORKDIR /app
COPY package.json ./
RUN npm install
COPY . .
EXPOSE 3000
CMD ["node", "index.js"]
```

## 🔧 Step-by-Step Lab Guide

---

### **STEP 1: Create an EC2 Instance**

1. Go to AWS Console → EC2 → Launch Instance.
2. **AMI**: Choose Amazon Linux 2 (x86).
3. **Instance Type**: `t2.micro` (Free Tier).
4. **Key Pair**: Create or select existing.
5. **Security Group**:

   * Allow **SSH (port 22)** from your IP.
   * Allow **HTTP (port 80)** from Anywhere.
   * Allow **MySQL/Aurora (port 3306)** from EC2 + your IP.
6. Launch Instance and connect via SSH:

   ```bash
   ssh -i "your-key.pem" ec2-user@<public-ip>
   ```

---

### **STEP 2: Install Docker on EC2**

```bash
sudo yum update -y
sudo yum install docker -y
sudo service docker start
sudo usermod -aG docker ec2-user
```

Log out & back in to activate Docker group.

---

### **STEP 3: Setup AWS RDS (MySQL)**

1. Go to **RDS → Create Database**.
2. **Engine**: MySQL
3. **DB Instance Identifier**: `database-1`
4. **Username**: `admin`, Password: `yourpassword`
5. **VPC & Subnet**: Default
6. Enable **Public Access**: ✅ Yes
7. Create a new **Security Group**:

   * Allow **MySQL (port 3306)** from EC2’s IP or EC2 Security Group.
8. Wait for DB to become **Available**.
9. Copy the **Endpoint** (e.g. `database-1.cxumw2gemspm.eu-north-1.rds.amazonaws.com`).

---

### **STEP 4: Prepare Your Node.js App**

📁 Inside EC2, create a project folder:

```bash
mkdir node-mysql-app && cd node-mysql-app
```

Create files:

---

#### `package.json`

```json
{
  "name": "node-mysql-app",
  "version": "1.0.0",
  "main": "index.js",
  "scripts": {
    "start": "node index.js"
  },
  "dependencies": {
    "express": "^4.18.2",
    "mysql": "^2.18.1"
  }
}
```

---

#### `index.js`

```js
const express = require('express');
const mysql = require('mysql');
const app = express();
app.use(express.json());

// 🔗 Connect to RDS
const connection = mysql.createConnection({
  host: 'database-1.cxumw2gemspm.eu-north-1.rds.amazonaws.com',
  user: 'admin',
  password: 'yourpassword',
  database: 'practice_db'
});

connection.connect(err => {
  if (err) throw err;
  console.log("✅ Connected to RDS MySQL");
});

// Routes
app.get('/', (req, res) => {
  res.send("✅ App is live and talking to MySQL RDS!");
});

app.post('/add', (req, res) => {
  const { email } = req.body;
  connection.query('INSERT INTO emails (email) VALUES (?)', [email], (err) => {
    if (err) throw err;
    res.send("📩 Email added");
  });
});

app.put('/update', (req, res) => {
  const { oldEmail, newEmail } = req.body;
  connection.query('UPDATE emails SET email=? WHERE email=?', [newEmail, oldEmail], (err) => {
    if (err) throw err;
    res.send("✏️ Email updated");
  });
});

app.delete('/delete', (req, res) => {
  const { email } = req.body;
  connection.query('DELETE FROM emails WHERE email=?', [email], (err) => {
    if (err) throw err;
    res.send("🗑️ Email deleted");
  });
});

app.listen(3000, () => {
  console.log("🚀 Server running on port 3000");
});
```

---

#### `Dockerfile`

```dockerfile
FROM node:18
WORKDIR /app
COPY package*.json ./

COPY . .
EXPOSE 3000
CMD ["npm", "start"]
```
