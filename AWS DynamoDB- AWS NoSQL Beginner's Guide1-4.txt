# 💡 DynamoDB Lab Demo – Beginner Friendly (Hindi Explanation)

## 🧠 Overview:

* DynamoDB: AWS की **fully managed NoSQL database service** है।
* यह **serverless**, **auto-scalable**, और **flexible** schema वाली database होती है।
* इसमें data JSON-like format (key-value pairs) में store होता है।

---

## 🔧 Step-by-Step Practical Lab:

---

### 🟢 Step 1: AWS Console में Login करें

1. **[https://console.aws.amazon.com/](https://console.aws.amazon.com/)** पर जाएं।
2. अपना **AWS account** credentials से login करें।

---

### 🟢 Step 2: DynamoDB Console खोलें

1. Search bar में **DynamoDB** type करें और क्लिक करें।
2. आप "Managed NoSQL database" वाले section में पहुँच जाएंगे।

---

### 🟢 Step 3: Create DynamoDB Table

1. **"Create Table"** बटन पर क्लिक करें।
2. Fill details:

   * **Table Name**: `contacts`
   * **Partition key**: `id`

     * Type: String
3. बाकी default settings रहने दें।
4. नीचे जाकर **Create Table** पर क्लिक करें।

➡️ आपकी table बन जाएगी और कुछ सेकंड में “Active” दिखेगा।

---

### 🟢 Step 4: Add Items (Manually)

अब हम manually data add करेंगे:

1. Table में क्लिक करें → **Explore Table Items**
2. Right side में **Create Item** पर क्लिक करें।
3. JSON format में data add करें:

```json
{
  "id": "01",
  "userName": "Raju"
}
```

➡️ **Create Item** पर क्लिक करें।

फिर दूसरा item add करें:

```json
{
  "id": "02",
  "userName": "Shyam",
  "age": 30
}
```

➡️ DynamoDB flexible है, हर item का schema अलग हो सकता है।

---

### 🟢 Step 5: Table Explore / Read Items

* आप Explore Table Items में जाकर सभी items को देख सकते हैं।
* हर item को individually open करके update भी कर सकते हैं।

---

### 🛠️ Step 6: Important DynamoDB Features

| Feature               | Explanation                                   |
| --------------------- | --------------------------------------------- |
| **Serverless**        | आपको server/infra manage नहीं करना            |
| **Auto-scaling**      | Read/Write requests के हिसाब से scale होता है |
| **No cost when idle** | Zero activity = zero cost                     |
| **Flexible schema**   | हर row अलग-अलग format में हो सकती है          |

---

### 🟠 Advanced Info (Optional – Read/Write Capacity):

* DynamoDB दो mode देता है:

  * **On-Demand**: Pay-per-request (Good for low traffic)
  * **Provisioned**: Fixed Read/Write capacity (Good for steady workloads)
* Auto-scaling enabled होने पर min/max capacity सेट कर सकते हैं।

## 🧑‍💻 Step 4: Node.js App बनाना (Locally or EC2 में)

`index.js`

```js
const express = require("express");
const mysql = require("mysql2");
const app = express();
app.use(express.json());

const db = mysql.createConnection({
  host: "your-rds-endpoint",
  user: "admin",
  password: "yourpassword",
  database: "contacts"
});

db.connect(err => {
  if (err) throw err;
  console.log("MySQL connected!");
});

// Add Contact
app.post("/add", (req, res) => {
  const { name, email } = req.body;
  db.query("INSERT INTO users (name, email) VALUES (?, ?)", [name, email], err => {
    if (err) return res.send(err);
    res.send("User added!");
  });
});

// Get All
app.get("/contacts", (req, res) => {
  db.query("SELECT * FROM users", (err, results) => {
    if (err) return res.send(err);
    res.json(results);
  });
});

// Update
app.put("/update/:id", (req, res) => {
  const { name, email } = req.body;
  db.query("UPDATE users SET name=?, email=? WHERE id=?", [name, email, req.params.id], err => {
    if (err) return res.send(err);
    res.send("Updated!");
  });
});

// Delete
app.delete("/delete/:id", (req, res) => {
  db.query("DELETE FROM users WHERE id=?", [req.params.id], err => {
    if (err) return res.send(err);
    res.send("Deleted!");
  });
});

app.listen(3000, () => console.log("Server running on port 3000"));
```

const express = require("express");
